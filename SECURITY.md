# Security Policy

## Supported Versions

This project is actively maintained on the `main` branch.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue first.

1. Email the maintainer with a clear description and reproduction steps.
2. Include affected files, dependency versions, and potential impact.
3. Allow time for triage and a coordinated fix before disclosure.

## Scope

Security reports are most helpful when they involve:

- Dependency vulnerabilities in runtime packages.
- Unsafe file handling or command execution.
- Data exposure in logs, artifacts, or outputs.
