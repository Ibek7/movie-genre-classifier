# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent and ask clarifying questions.
- Focus feedback on code and ideas, not people.
- Help keep discussions welcoming and inclusive.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Disruptive trolling or hostile communication.

## Scope

This Code of Conduct applies in project spaces, including issues, pull requests, and discussions.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainer privately with details and context.

## Enforcement

Maintainers may remove, edit, or reject comments and contributions that violate this policy.
